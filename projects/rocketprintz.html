WEB & MOBILE APP

RocketPrintz

A production management and raw material inventory system for Rocket Printz, a printing, screen printing, apparel, and merchandise business.

01 // OVERVIEW

Project Context

RocketPrintz was built as an internship (Kerja Praktik) project at Rocket Printz. It replaces manual record keeping with one application that covers three processes: order management, production planning, and raw material inventory. Access is split across three roles: Admin, Supervisor, and Operator.

02 // ENGINEERING

Architecture & Implementation

The app is built with Expo and React Native in TypeScript, with a single codebase for the web and Android versions. Navigation uses file-based Expo Router, and every page can only be opened by the role that owns it.

Login uses Firebase Authentication with an email or a username. Orders, plans, materials, and users live in Cloud Firestore, so a change made by one role shows up for the others in real time.

Supervisors can print a Work Order from the planning page. The web version is deployed on Vercel under a custom domain, and the Android version is built as an APK through EAS Build.

03 // FEATURES

Key Technical Features

✓Order management for admins
✓Production planning and scheduling
✓Real-time monitoring of running production for supervisors
✓Operators see their own schedule, then start and finish production
✓Raw material inventory with stock levels and minimum stock
✓Role-based access, printable Work Orders, summary dashboards, and search
